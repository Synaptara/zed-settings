## Features

- **Solarized Osaka** — A dark, blue-black aesthetic with muted foregrounds and cyan accents.
- **Minimal UI** — Clean editor layout with reduced visual clutter.
- **Fast workflow** — Lightweight settings focused on productivity.
- **Django & React** — Configured for Python backend and React frontend development.
- **AI-free editing** — No built-in AI distractions.

## Installation

1. Install [Zed](https://zed.dev/).
2. Back up your existing settings.
3. Clone this repository:

   ```bash
   git clone https://github.com/Synaptara/zed-settings.git
   ```

4. Copy the configuration into your Zed settings directory, or manually merge it with your existing settings.

   **Linux:**
   ```bash
   cp settings.json ~/.config/zed/settings.json
   ```

   Back up your current configuration before replacing it.
